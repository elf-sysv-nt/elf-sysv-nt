== capability

    cpuid leaf 7 FSGSBASE      yes
    IsProcessorFeaturePresent  yes
    the instruction executes   yes
    %fs:0 addresses through it yes

    The first two report what the processor and the loader
    believe. CR4.FSGSBASE is the kernel's to set, so the third
    one is the evidence and the fourth says the base is used
    for address translation rather than merely remembered.

== observations

    thread start     starts at zero
    fork             the child's base is 0x0

    Neither of these is a pass or a fail. The loader sets the
    base at thread start and can set it again after a fork; what
    matters is that the answer is the same every time.

== the red zone

                       passes   events words lost  nearest furthest
    rz-quiet           200000        0          0        0        0
    rz-preempt         200000       12          0        0        0
    rz-hijack            1339     2000          0        0        0
    rz-signal          600785     2000      73992      320      648
    rz-veh               2000     2000      73963      272      600

    Nearest and furthest are distances below the watched %rsp,
    in bytes. The watcher only ever looked 1024 bytes down, so a
    furthest equal to that is a floor and not a measurement, and
    the furthest under rz-veh counts this probe's own handler
    frames as well as the host's. Nearest is the number that
    decides the policy, because it is where the writing starts.
    Under rz-preempt the events column counts burner threads:
    preemptions cannot be counted from the thread they hit.
